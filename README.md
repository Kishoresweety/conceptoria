# conceptoria
Learn everything in new way

## I built something because I was tired of memorizing computer science concepts.

Conceptoria is a small visual learning project where concepts like:
• pointers
• stack vs heap
• malloc/free
• segmentation faults
• process memory

are explained using simple animations instead of long theory.

This is not a course.
No certificates.
No buzzwords.

Just mental models.

If you're learning C, OS, or preparing for interviews, this might help.
